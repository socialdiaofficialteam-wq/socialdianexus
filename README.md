# Socialdia Nexus — منصة لإدارة وكالات التسويق

صفحة رئيسية عامة (شرح النظام، المميزات، طريقة الاستخدام، الباقات بالجنيه، الأسئلة) + تطبيق الوكالة (عملاء، مهام Kanban، تقويم محتوى، أدوات AI) + **لوحة أدمن** للتحكم في محتوى الموقع كله. عربي/إنجليزي مع RTL، وألوانه من اللوجو.

مفيش build ولا dependencies: ملفات ثابتة + Function واحدة للـ AI + Supabase للحسابات والبيانات.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الوحيدة (الصفحة الرئيسية + الدخول + التطبيق + لوحة الأدمن) |
| `styles.css` | التصميم (ألوان اللوجو بتتغير من لوحة الأدمن) |
| `app.js` | التطبيق: عملاء، مهام، تقويم، AI، دخول، مزامنة Supabase |
| `site.js` | الصفحة الرئيسية + محرر الموقع (للأدمن) |
| `logo-mark.png` | علامة اللوجو (خلفية شفافة) |
| `config.js` | بيانات الاتصال بـ Supabase (Project URL + anon key) |
| `schema.sql` | الجداول وسياسات الأمان (RLS)، يتشغل مرة واحدة |
| `api/ai.js` | Function للـ AI على Vercel: بتخبّي المفتاح، وبتتحقق من الدخول وبتحدد الاستخدام |
| `functions/api/ai.js` | نفس الـ Function بصيغة Cloudflare Pages |

## أوضاع التشغيل
- **محلي** (`config.js` فاضي): من غير تسجيل دخول، وكل شيء محفوظ في متصفحك، وإنت الأدمن تلقائياً. مناسب للتجربة بس.
- **سحابي** (`config.js` متعبّي): تسجيل دخول، وكل مستخدم بياناته على حسابه ومحمية بـ RLS، ومحتوى الموقع بيظهر لكل الزوار.

## الإعداد خطوة بخطوة

### 1) Supabase (مجاني)
1. أنشئ مشروع على supabase.com.
2. **SQL Editor ← New query**، الصق محتوى `schema.sql` واضغط Run.
3. **Project Settings ← API**: انسخ **Project URL** و **anon (publishable) key** وحطهم في `config.js`. (لا تحط `service_role` أبداً.)
4. **Authentication ← URL Configuration**: حط رابط موقعك في *Site URL*.
5. وقت التجربة تقدر توقف *Confirm email*، وفعّله قبل الإطلاق.

### 2) النشر على Vercel (مجاني)
1. ارفع كل الملفات على مستودع GitHub (وخلّي `ai.js` جوه فولدر `api`).
2. من Vercel: **Add New ← Project** ← اختار المستودع ← **Deploy**.
3. **Settings ← Environment Variables**:
   - `ANTHROPIC_API_KEY` — لتفعيل الـ AI الحقيقي
   - `SUPABASE_URL` و `SUPABASE_ANON_KEY` — نفس قيم `config.js` (بيهم الـ AI بيبقى للمسجلين بس، مهم قبل ما تشارك الرابط)
   - اختياري: `AI_HOURLY_LIMIT` (الافتراضي 30 طلب/ساعة لكل مستخدم)، `AI_MODEL`
4. **Redeploy**.

### 2-ب) النشر على Cloudflare Pages (بديل لـ Vercel، مجاني وبيسمح بالتجاري)
1. ارفع الملفات على GitHub (فولدر `functions/` هو بتاع الـ AI على Cloudflare، و`api/` بتاع Vercel وبيتجاهله Cloudflare).
2. Cloudflare ← **Workers & Pages** ← **Create** ← **Pages** ← **Connect to Git** ← اختار المستودع.
3. Framework preset = None، وسيب Build command فاضي، وOutput directory = `/`. ثم **Save and Deploy**.
4. **Settings ← Variables and Secrets**: أضف `ANTHROPIC_API_KEY` (Secret) و`SUPABASE_URL` و`SUPABASE_ANON_KEY` (واختياري `AI_HOURLY_LIMIT`, `AI_MODEL`)، ثم **Redeploy**.
5. في Supabase ← Authentication ← URL Configuration: حط رابط `*.pages.dev` في *Site URL* و*Redirect URLs*.

### 3) أول أدمن
1. افتح موقعك، واضغط **ابدأ الآن**، وسجّل حساب بإيميلك.
2. في Supabase ← SQL Editor شغّل (بدّل الإيميل بإيميلك):
   ```sql
   insert into public.admins (user_id)
     select id from auth.users where email = 'YOUR_EMAIL@example.com'
     on conflict do nothing;
   ```
3. سجّل خروج وادخل تاني: هيظهر في القايمة الجانبية **إدارة الموقع**.

> الأدمن بيتحدد من جدول `admins` بس، ومينفعش حد يبقى أدمن من داخل الموقع.

## لوحة الأدمن (إدارة الموقع)
بتتحكم من هنا في: اسم المنصة والشعار (رفع صورة)، **ألوان الموقع**، شريط الإعلان، إظهار/إخفاء "إنشاء حساب"، عناوين الصفحة الرئيسية وشرح النظام، **المميزات**، **خطوات الاستخدام**، **الباقات والأسعار بالجنيه** (إضافة/حذف/ترتيب/"الأكثر طلباً")، **الأسئلة الشائعة**، وبيانات التواصل (واتساب، إيميل، سوشيال) والفوتر. كل نص عربي وإنجليزي.
- أي تعديل بيتحفظ بزرار **حفظ التغييرات** وبيظهر لكل الزوار.
- زرار الاشتراك في الباقة بيفتح واتساب برسالة جاهزة لو كتبت رقم واتساب في "التواصل"، وإلا بيودّي الزائر لإنشاء حساب.

## المستخدمون والاشتراكات (من لوحة الأدمن)
تبويب **المستخدمون والاشتراكات** في إدارة الموقع (محتاج Supabase وتشغيل أحدث `schema.sql`):
- قايمة كل المستخدمين مع بحث بالإيميل، وإحصائيات: عدد المستخدمين، المشتركين النشطين، الموقوفين، والدخل الشهري المتوقع.
- لكل مستخدم: اختيار **الباقة** (بيملا الحد وتاريخ انتهاء بعد 30 يوم تلقائياً وتقدر تعدّلهم)، **حد العملاء** (فاضي = بلا حد)، **تاريخ الانتهاء**، **الحالة** (نشط / موقوف)، وزرار ترقية/إلغاء أدمن.
- بعد انتهاء الاشتراك الحساب بيرجع لحد "بدون اشتراك" (الافتراضي 3 عملاء، بيتغير من الهوية والألوان ← خيارات، و0 = بلا حد).
- **الحدود مفروضة في قاعدة البيانات** (trigger) مش في الواجهة بس: الإضافة فوق الحد أو من حساب موقوف بتترفض. الأدمن مستثنى. تعديل أو حذف الموجود مش بيتأثر.
- الحساب الموقوف بيشوف شاشة "الحساب موقوف" مع زرار واتساب، والمستخدم العادي بيشوف باقته وعدد عملائه في القايمة الجانبية.
- حد العملاء بيتحدد لكل باقة من تبويب الباقات، وبيظهر تلقائياً أول بند في الصفحة الرئيسية.
- التفعيل حالياً يدوي بعد التواصل عبر واتساب. الدفع الإلكتروني لسه.

## ملاحظات مهمة
- **إخفاء "إنشاء حساب"** بيخفي الزرار بس. لإيقاف التسجيل فعلياً: Supabase ← Authentication ← Sign In / Providers ← تعطيل Sign-ups.
- **الأسعار الافتراضية** (299 / 699 / 1499 جنيه) أمثلة تقدر تغيّرها من لوحة الأدمن.
- خطة Vercel Hobby للاستخدام الشخصي فقط، فانتقل لـ Pro عند أول عميل بيدفع.
